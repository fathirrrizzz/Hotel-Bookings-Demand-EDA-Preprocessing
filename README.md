# Hotel Bookings — Exploratory Data Analysis & Preprocessing

## Deskripsi
Proyek ini membahas eksplorasi data dan preprocessing pada dataset Hotel Booking Demand menggunakan Python, Pandas, NumPy, Matplotlib, Seaborn, dan SciPy.

## Tujuan
- Memahami struktur dan karakteristik dataset.
- Menganalisis missing values dan duplikasi.
- Memvisualisasikan distribusi data menggunakan histogram, boxplot, dan QQ plot.
- Mengidentifikasi kandidat outlier menggunakan metode Interquartile Range (IQR).
- Melakukan preprocessing dan memvalidasi hasilnya.

## Tools
- Python
- Google Colab / Jupyter Notebook
- Pandas dan NumPy
- Matplotlib dan Seaborn
- SciPy

## Struktur Proyek
- `Hotel_Bookings_Preprocessing.ipynb` — notebook analisis dan preprocessing.
- `README.md` — dokumentasi proyek.

## Cara Menjalankan
1. Unduh notebook dari repository.
2. Buka Google Colab.
3. Unggah notebook dan dataset `hotel_bookings.csv`.
4. Jalankan sel secara berurutan.

## Catatan
Kandidat outlier tidak otomatis dihapus. Penanganan missing values dan keputusan preprocessing perlu mempertimbangkan karakteristik data serta tujuan analisis.
